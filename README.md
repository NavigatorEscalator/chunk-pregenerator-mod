## 📖 About

Chunk Pregenerator generates chunks in a configurable radius around a centre point, eliminating lag spikes from lazy chunk loading during exploration or farm startup.

---

## ✨ Features
<a name="features"></a>

- **Configurable Radius** — pregenerate any square or circular area.
- **Progress HUD** — chunks/s, estimated time, and percentage done.
- **Pause/Resume** — stop without losing progress.
- **Priority Mode** — generate only visible chunks first.
- **Disk Space Estimate** — shows expected region file size before starting.
- **Report** — logs total chunks generated and time taken.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
